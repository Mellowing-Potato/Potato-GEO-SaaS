# 言及 · 浏览器发布助手 0.4.0

支持将言及“进行中”的知乎、微博文章发布单保存到当前 Chrome 用户已登录账号的草稿。
扩展不读取知乎 Cookie、密码或令牌，不点击“发布”。最终发布和公开链接登记由用户完成。

## 用户安装与使用

0.4.0 按实例配置生成专属安装包，精确区分协议、主机名和端口。不同实例请解压到不同目录并分别加载；不要直接加载源码目录。更新同一实例时覆盖原安装目录并重新加载，实例地址改变时重新下载。缓存只属于包中标明的实例，回传只交给发起任务的页面；页面关闭或跳到别处后不会把内容发给新页面。

1. 在言及“手动发布”页面的“浏览器发布助手与使用说明”下载安装包并解压。下载需要当前租户的发布权限；安装包只包含固定扩展文件，不包含租户内容或凭据。
2. 在 Chrome 打开 `chrome://extensions`，开启“开发者模式”，选择“加载已解压的扩展程序”，指向解压目录。
3. 使用同一个 Chrome 用户资料登录言及和知乎。言及“人设与账号”中为知乎账号填写完整个人主页链接。
4. 将知乎文章发布单推进到“进行中”，在详情中点击“同步到知乎草稿”。
5. 扩展核对知乎实际登录账号，填入标题与正文，等待知乎草稿保存提示。若无法确认保存，言及会明确提示人工检查，不登记草稿链接。
6. 在知乎检查草稿并自行发布，再将公开文章链接填入言及的“完成”表单。

0.2.4 会等待知乎页头账号信息稳定后再核对身份，并在菜单首次未展开时重试；真正不一致时会显示绑定与实际识别的主页标识，并停止写入。多段正文通过编辑器的粘贴入口作为完整片段写入，不读取系统剪贴板。知乎将网址显示为网页标题时，按真实引用目标核对，不把展示标题的变化当成正文丢失；引用目标错误或正文缺失仍失败。这是所有项目与账号共用的逻辑，不含特定用户的例外。升级后请刷新言及发布单页面，并从产品按钮重新同步。

0.2.5 继续处理重复同步：如果已关联草稿的标题、正文和引用目标均已一致，且平台显示已保存，就核对并记录，不强迫平台再保存一次；内容需要改写时仍等待新的保存回执。保存提示组件重新渲染也会重新读取当前状态。

0.2.6 在判断是否改写前等待已有草稿内容和保存提示加载稳定，避免首次读取过早便重复写入；平台保存未就绪时停止覆盖。新写入最多等待60秒，未确认时区分平台尚未保存与未观察到新保存回执。

0.2.7 在已有保存基线后开始改写时，也观察保存提示组件暂时消失、随后重新显示已保存的过渡；必须同时核对标题、完整正文和引用目标，才会登记。

重新同步已关联草稿会要求确认覆盖；若编辑器出现未预期的现有内容，扩展停止写入。
知乎目前只支持纯文本标题和正文，不同步图片、富文本格式、话题或封面。知乎编辑器结构变更时，扩展会报错并保留人工发布流程。

## 微博一键保存草稿（0.3.0）

0.3.1 修复保存后重新打开草稿的页面跳转竞争，并区分微博编辑器的无图片地址排版占位与文章图片。核对正文、引用与实际图片的要求不变。新旧草稿可以同时存在，不要求清空草稿箱。

同一 Chrome 用户资料登录微博与言及，在言及微博账号中填写 `https://weibo.com/u/数字账号ID`。进行中的文章发布单填写最多 32 个 UTF-16 字符的渠道标题，点击“发送到微博草稿箱”。助手打开微博文章编辑器，核对页头实际登录账号，通过同源网页草稿接口新建草稿、保存 HTML 正文及链接；最多 20 张 HTTPS 正文图片先转存至微博图床，任一失败停止，不静默丢图。此接口不是微博开放平台的官方 API，平台改版可能需要适配。封面和正式发布请在微博完成。

保存后重新加载返回的草稿页面，回读标题、完整正文、链接与图片；只有核对一致才回传言及。发送回执与原人工确认分别保存，发布单仍为进行中。账号不符、审核版本过期或言及不能确认发送步骤时停止写入。重复点击不新建：已有草稿编号只允许重新打开核对，不覆盖用户编辑；创建结果未知且未取得编号时阻止再次创建，请先人工查看微博草稿箱。页面关闭、浏览器退出或网络中断不自动重发。

从旧版本更新时，重新从言及下载解压，Chrome 扩展管理页选择新版目录或在原安装目录用完整新包替换并重新加载；允许新增的微博编辑页访问后刷新言及页面。无需 Cookie 权限，不读取浏览器 Cookie、密码或登录令牌；微博请求只在已登录的微博编辑页通过浏览器会话执行。

安装包顶部标明实例地址、实例标识和版本。扩展只对该实例的 `/manual-publish`、`zhuanlan.zhihu.com` 的文章编辑页及 `card.weibo.com/article/v5/editor` 注入脚本。
当前通过言及提供带版本号的安装包下载，尚未在 Chrome Web Store 上架，不声称已通过商店审核。每个租户使用自己的平台账号和本机浏览器登录状态；发布单正文在同步前由言及接口按工作区、账号、审核版本和发布单版本重新校验。平台 Cookie、密码和登录令牌不上传言及。

用户可以不用扩展，继续走打开平台、复制正文和回填结果的完整流程。运营可通过 `GEO_ZHIHU_DRAFT_SYNC_ENABLED=false` 关闭知乎草稿辅助；该开关不影响其他人工发布功能。
